# «Черноголовка Клуб» — Telegram-бот + мини-приложение

Один сервис на Railway делает всё:
- **бот** (aiogram 3): кнопка «Открыть клуб», описание бота, меню, админ-команды, рассылки, выдача призов, импорт базы и кодов;
- **сервер** (aiohttp): раздаёт мини-апп и отвечает на его запросы `/api/*`;
- **база** (PostgreSQL на Railway или SQLite локально): пользователи, баллы, коды, игры, призы, журнал начислений.

Все баллы, лимиты и призы считает сервер. Каждый запрос мини-аппа проверяется по подписи Telegram, поэтому подменить пользователя или начислить себе баллы с телефона нельзя.

## Запуск на Railway (≈15 минут)

1. Загрузите эту папку в новый приватный репозиторий GitHub.
2. Railway → **New Project → Deploy from GitHub repo** → выберите репозиторий.
3. В проекте: **New → Database → PostgreSQL**. Railway сам передаст `DATABASE_URL` в сервис (проверьте во вкладке Variables сервиса: `DATABASE_URL = ${{Postgres.DATABASE_URL}}`).
4. Сервис → **Settings → Networking → Generate Domain**. Получите адрес вида `https://chg-club.up.railway.app`.
5. Сервис → **Variables**:
   - `BOT_TOKEN` — токен бота из @BotFather;
   - `WEBAPP_URL` — адрес из шага 4;
   - `ADMIN_IDS` — ваш Telegram ID (и коллег) через запятую;
   - `DEMO_CODES` — `0` (или `1` на время теста, чтобы работали тестовые коды).
6. Railway перезапустит сервис. В логах должно быть `web on :PORT` и `Start polling`.
7. Откройте бота → /start → «Открыть клуб». Админам доступна /help.

Команда запуска берётся из `Procfile`: `python -m app.main`.

## Переезд с текущего бота без потери аудитории

Аудитория привязана к **токену бота**, а не к коду. Порядок:
1. Получите у прошлого разработчика выгрузку пользователей (минимум — Telegram ID; лучше ID + баллы).
2. Запустите новый сервис с **тем же токеном** — старый бэкенд в этот момент нужно остановить (два сервера на одном токене работать не могут). Перерыв — пара минут.
3. Админ присылает боту CSV с подписью `/import_users`. Формат: `telegram_id,баллы,имя` (заголовок можно оставить). Баллы переносятся один раз на пользователя, повторный импорт их не задвоит.
4. `/announce` — анонс «Не расходитесь, промо-бот превращается в клуб».
5. В день релиза: отправьте боту видеоинструкцию с подписью, ответьте на неё `/broadcast` → «Отправить». Видео уйдёт всем с кнопкой «Открыть клуб».

Если у вас только тестовый бот (@test_mustafin_bot), всё то же самое можно сначала проверить на нём.

## Коды из-под крышек

Коды хранятся в таблице `codes`. Загрузка — CSV с подписью `/import_codes` (или `python -m scripts.import_csv codes codes.csv`). Формат строки: `CHG-XXXX-XXXX[,id_подарка]`; если указан id приза (например `stick`), пользователь получит этот подарок вместе с баллами.

Нужно сгенерировать коды самим: `python -m scripts.gen_codes 10000 codes.csv --gift stick:200` (каждый 200-й — с подарком).

Защита: код засчитывается один раз; после 5 неверных попыток за 10 минут ввод блокируется на 10 минут.

## Админ-команды

| Команда | Что делает |
|---|---|
| /stats | пользователи, активность, коды, заявки на призы |
| /claims | заявки на призы → кнопка «✅ Выдан» уведомляет пользователя |
| /announce | анонс перехода в клуб всем пользователям |
| /broadcast | ответом на любое сообщение (текст/фото/видео) — рассылка всем с кнопкой клуба |
| /import_users, /import_codes | CSV-файл с такой подписью |
| /prizes, /stock ID N | остатки призов |
| /ban ID, /unban ID | скрыть накрутчика из рейтинга и запретить начисления |

Рассылка идёт ~25 сообщений/с (лимит Telegram), заблокировавшие бота помечаются и больше не получают сообщений.

## Правила, которые держит сервер

- Уровни: Бронза 0+ (10 баллов за код), Серебро 300+ (12), Золото 1000+ (15). Уровень считается от всех накопленных баллов и не падает при покупке призов.
- Игры: баллы только за первые 3 попытки в каждой игре в день, не больше 15 за игру и 40 в день. Попытка засчитывается при старте. Результат отклоняется, если очков больше реально возможного или партия закончилась подозрительно быстро.
- «Миксуй» («Подобрать вкус»): таймер на выбор 9 → 4 с, ошибка или нехватка времени — конец игры.
- «Крышка дня»: одна в день, исход решает сервер.
- Опрос +30 (один раз), дата рождения +50 (указать можно один раз).
- Рейтинг — только по кодам; забаненные скрыты. Победители дня — призы, выданные сегодня.
- Все изменения баллов пишутся в таблицу `ledger` (для разбора спорных случаев и аналитики).

## Локальный запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполните, затем экспортируйте переменные
BOT_TOKEN=... WEBAPP_URL=https://... python -m app.main
```
Без `BOT_TOKEN` (или с `RUN_BOT=0`) запускается только сервер. Мини-апп, открытый не из Telegram, работает в демо-режиме на тестовых данных.
